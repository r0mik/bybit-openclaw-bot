# Как запустить Mini Craft

## Самый простой способ — готовая сборка (Godot не нужен)

Скачайте архив для своей системы, распакуйте и запустите один файл:

| Система | Архив | Что запускать |
|---|---|---|
| Windows 10/11 (64-бит) | `MiniCraft_Windows.zip` | `MiniCraft.exe` — двойной клик |
| macOS на Apple M1/M2/M3/M4 | `MiniCraft_macOS_arm64.zip` | `Mini Craft - RTS Prototype.app` |
| macOS на Intel | `MiniCraft_macOS_x86_64.zip` | `Mini Craft - RTS Prototype.app` |
| Linux (x86_64) | `MiniCraft_Linux.zip` | `MiniCraft.x86_64` (в терминале: `chmod +x MiniCraft.x86_64 && ./MiniCraft.x86_64`) |

Какой у вас Mac — видно в меню  → «Об этом Mac» (строка «Чип» или «Процессор»).

Игра — это один файл, внутри уже всё: графика, карта, ИИ. Установка не требуется.

- **Windows** может показать «Windows защитила ваш компьютер» (файл без цифровой подписи):
  нажмите **«Подробнее» → «Выполнить в любом случае»**.
- **macOS** при первом запуске: **ПКМ (или Ctrl+клик) по приложению → «Открыть» → «Открыть»**.
  Если пишет «повреждено»: в Терминале выполните
  `xattr -cr "/путь/к/Mini Craft - RTS Prototype.app"` и запустите снова.

Дальше — способ для тех, кто хочет открыть игру в редакторе Godot и менять её.

## 1. Скачайте Godot (бесплатно, установка не нужна)

1. Откройте **https://godotengine.org/download**
2. Выберите свою систему и скачайте **Godot Engine 4.3 или новее** — обычную версию
   (**не** «.NET / C#»).
3. Распакуйте архив. Внутри один файл — это и есть Godot:
   - Windows: `Godot_v4.x-stable_win64.exe`
   - macOS: `Godot.app` (перетащите в «Программы»)
   - Linux: `Godot_v4.x-stable_linux.x86_64`

## 2. Скачайте игру

Любой из вариантов:

- **Архив из чата** `MiniCraft_RTS.zip` — распакуйте в любую папку.
- **С GitHub:**
  https://github.com/r0mik/bybit-openclaw-bot/archive/refs/heads/claude/trading-bot-bybit-u4vyv.zip
  — распакуйте, игра лежит в папке `rts_prototype`.
- **Через git:**
  ```
  git clone -b claude/trading-bot-bybit-u4vyv https://github.com/r0mik/bybit-openclaw-bot.git
  ```

## 3. Откройте и запустите

1. Запустите Godot.
2. В окне «Менеджер проектов» нажмите **Импорт** (Import).
3. Укажите файл **`project.godot`** в папке игры (`MiniCraft_RTS` или `rts_prototype`) →
   **Импорт и редактирование**.
4. Первый раз Godot ~10–30 секунд импортирует текстуры — подождите.
5. Нажмите **F5** (или кнопку ▶ «Запустить проект» справа вверху). Игра откроется в окне.

В следующий раз проект уже будет в списке менеджера — двойной клик, затем F5.

## Управление

| Действие | Как |
|---|---|
| Выбрать | ЛКМ по юниту/зданию, или рамка мышью; Shift — добавить к выбору |
| Приказ (идти / атаковать / добывать) | ПКМ |
| Атака с продвижением | `A`, затем ЛКМ |
| Стоп / держать позицию | `S` / `H` |
| Строить (выбран рабочий) | `D` склад, `B` казарма, `U` бункер, `E` инж. отсек, `T` турель, `F` завод, `P` космопорт, `C` командный центр |
| Нанимать (выбрано здание) | `Q` рабочий/пехота, `T` танк, `W` истребитель; `X` — отмена |
| Улучшения (инж. отсек) | `W` оружие, `R` броня |
| Группы | `Ctrl+1..9` — назначить, `1..9` — выбрать, двойное нажатие — к группе |
| Камера | стрелки или мышь у края экрана, колесо — приближение, средняя кнопка — перетаскивание, `Space` — к базе, клик по миникарте |
| Заново после конца игры | `R` |

**Цель:** добывайте минералы рабочими, стройте армию и уничтожьте все здания красного противника.

## Если что-то не так

- **Ошибки при открытии / «проект создан в более новой версии»** — нужна Godot **4.3+**, обычная (не .NET).
- **Медленно работает** — так бывает на слабой встроенной графике. В Godot: *Проект → Настройки проекта →
  Rendering → Renderer* поставьте **Compatibility** и перезапустите. Картинка станет чуть проще (без SSAO).
- **Чёрный экран / не стартует на старом ПК** — тоже переключите рендерер на **Compatibility** (см. выше).
- **macOS пишет, что приложение от неизвестного разработчика** — ПКМ по Godot.app → «Открыть» → «Открыть».

## Как самому пересобрать .exe после изменений

Настройки экспорта уже в проекте (`export_presets.cfg`: Windows, macOS, Linux).
В Godot: *Проект → Экспорт…* → выберите платформу → при первом разе «Управление шаблонами экспорта» →
«Скачать и установить» → **«Экспорт проекта»**. Получится один файл, который запускается без Godot.

Из командной строки: `godot --headless --path . --export-release "Windows Desktop" build/MiniCraft.exe`
