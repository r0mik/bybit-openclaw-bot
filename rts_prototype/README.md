# Mini Craft — прототип RTS в стиле StarCraft (Godot 4)

**Графика 2.5D, как в StarCraft:** 3D-модели (собраны из примитивов в `tools/models.gd`) заранее
рендерятся ортографической камерой под углом 50° в спрайты с тенями; юниты — в 16 направлениях.
Сама игра остаётся 2D: логика, коллизии и выделение работают на плоскости.

Модели можно открыть в редакторе Godot: `models/*.tscn` (сохраняются при рендере).

### Пересборка графики
Нужны Python 3 (Pillow, numpy) и Godot 4.3+:
```
GODOT=/путь/к/godot tools/build_assets.sh
```
Шаги: `gen_textures.py` (материалы и земля) → `render_sprites.gd` (3D-рендер, нужен дисплей,
на сервере используется `xvfb-run`) → `compose_sprites.py` (тени, листы кадров, `assets/sprites.json`).

## Запуск
1. Установите **Godot 4.3+** (обычная версия, не .NET).
2. Godot → *Import* → выберите `rts_prototype/project.godot` → **F5**.

## Что есть
- **Экономика:** рабочие (SCV) сами добывают минералы и относят их в Command Center.
- **Supply:** лимит армии; Supply Depot даёт +8, Command Center даёт +10 (максимум 200).
- **Стройка:** рабочий + `D` Depot, `B` Barracks, `F` Factory (нужен Barracks), `C` Command Center (на 3 точках расширения есть минералы).
- **Юниты:** SCV (`Q` в CC), Marine (`Q` в Barracks), Siege Tank (`T` в Factory, урон по площади).
- **Управление как в StarCraft:** рамка/клик для выбора, Shift — добавить в выделение, ПКМ — идти/атаковать/добывать,
  `A` + клик — атака с продвижением, `S` — стоп, `H` — держать позицию, `Ctrl+1..9` / `1..9` — группы
  (двойное нажатие центрирует камеру), ПКМ зданием — точка сбора, `X` — отмена производства.
- **Камера:** стрелки, край экрана, средняя кнопка мыши, колесо — зум, `Space` — к базе, миникарта (ЛКМ — камера, ПКМ — приказ).
- **ИИ противника** (красный): строит экономику, бараки и фабрику, защищает базу и атакует волнами, которые растут.
- **Победа:** уничтожьте все здания противника. `R` — заново.

## Структура
| Файл | Назначение |
|---|---|
| `scripts/defs.gd` | характеристики юнитов и зданий (баланс правится здесь) |
| `scripts/main.gd` | карта, ввод, выделение, приказы, бой, коллизии |
| `scripts/unit.gd` | юнит: машина состояний (движение, атака, добыча, стройка) |
| `scripts/building.gd` | здание: стройка, очередь производства, точка сбора |
| `scripts/ai.gd` | компьютерный противник |
| `scripts/hud.gd`, `scripts/minimap.gd` | интерфейс и миникарта |
| `tools/models.gd` | 3D-модели зданий, юнитов и минералов |
| `tools/render_sprites.gd`, `tools/compose_sprites.py` | рендер моделей в 2.5D-спрайты |
| `tools/gen_textures.py` | текстуры материалов и земли |
| `models/` | модели как сцены Godot (для просмотра в редакторе) |
| `assets/` | готовые спрайты (для синей и красной команды) |

## Автотест
`godot --headless --path . --fixed-fps 30 --quit-after 20000 -- --autotest` запускает матч «ИИ против ИИ»
и раз в 30 секунд печатает статистику.
